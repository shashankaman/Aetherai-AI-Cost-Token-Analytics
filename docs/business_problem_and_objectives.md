# Business Problem, Objectives & Scope

## Business scenario

AetherAI is a simulated organization using multiple AI models across business departments. Leadership wants to understand adoption, token consumption, API cost, request reliability, and the potential business value generated by AI-assisted work.

## Problem statement

AI usage creates operational and financial questions: which models drive spending, which departments consume the most resources, how reliably requests complete, and where optimization opportunities may exist. Without consolidated reporting, decision-makers may see total spend but lack the context needed to judge whether that spend is appropriate.

## Stakeholders

- Executive leadership: overall adoption, cost, reliability, and value.
- Finance: AI cost and budget monitoring.
- Department managers: usage patterns and cost drivers.
- AI operations / platform team: model performance, latency, errors, and timeouts.

## Objectives

1. Quantify request volume and token usage.
2. Calculate model-specific AI cost using input and output rates.
3. Compare usage and cost across models, departments, and months.
4. Measure request execution reliability.
5. Analyze task outcomes and estimated time value where source data supports it.
6. Present findings in a multi-page Power BI dashboard.
7. Recommend measurable cost and reliability improvements.

## Scope

Included: request-level analysis, token usage, model rates, department mapping, monthly trends, request statuses, dashboard reporting.

Conditional pending validation: monthly budget utilization, budget variance, estimated labor value, and estimated ROI.

## Questions answered

- How many AI requests were made during the analysis period?
- How many input, output, and total tokens were consumed?
- What was the estimated API cost based on the model rate card?
- Which model contributed the largest share of total cost?
- Which departments generated the most requests and cost?
- How did monthly AI cost change over time?
- What proportion of requests succeeded, errored, or timed out?
- Which model/task/department combinations should be investigated for optimization?
