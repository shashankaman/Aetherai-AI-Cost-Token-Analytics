## Suggested repository settings

- Public repository, if the data and files are safe to share.
- Add README.
- Add a suitable license if you want others to reuse the code; choose a license intentionally.
- Add `.gitignore`.
- Do not upload database passwords, API keys, private data, or unnecessary raw personal information.
- Add screenshots to `assets/dashboard_screenshots/` and embed them in README.
- Make sure the notebook runs from top to bottom or clearly documents required input paths.
