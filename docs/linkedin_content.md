## LinkedIn project post

I’m excited to share **AetherAI — AI Cost & Token Usage Analytics**, an end-to-end Data Analytics portfolio project.

As organizations adopt AI tools across teams, understanding usage and API costs becomes increasingly important. In this project, I analyzed AI request activity, token consumption, model-level costs, department usage, and request reliability.

**Tools used**
- PostgreSQL — data modeling, SQL analysis, joins and aggregations
- Python — data validation, analysis and reporting outputs
- Power BI — interactive dashboard and KPI reporting

**A few findings from the analysis**
- Analyzed 12,000 AI requests.
- Measured 30.45 million total tokens.
- Estimated approximately $37.90 in AI API cost using model-specific input/output token rates.
- Achieved a 95.63% request success rate in the dataset.
- Found that Aether-Pro represented 79.59% of total cost while handling 26.05% of requests.
- Identified opportunities to investigate model routing, request failures, and cost per successful task.

One important learning: the model with the highest cost is not automatically inefficient. Cost needs to be evaluated alongside task complexity, output quality, latency, and success rate.

This project strengthened my skills in SQL-based analysis, Python data validation, Power BI dashboarding, KPI design, and translating data into business recommendations.
